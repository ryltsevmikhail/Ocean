# Ocean

Ocean — проект на TypeScript для работы с постоянными ботами в личных и групповых чатах. Первый клиент — терминал. В целевой версии пользователь может обсудить работу с разработчиком наедине, а затем позвать его и ревьюера в общую комнату. Каждый бот видит историю той комнаты, в которой к нему обратились.

**Состояние проекта.** В каталоге работает исходная база Ocean с CLI, TUI, ACP v1, адаптером DeepSeek и SQLite для задач. Реализован M1 — прикладной API профилей ботов, личных комнат и сохраняемой истории пользовательских сообщений в SQLite. Реализован M2 — личные текстовые чаты через CLI/TUI и DeepSeek с восстановлением контекста после перезапуска. Реализован M3 — группы с постоянным составом, общей историей и явным выбором одного бота через --to или начальное @упоминание. Для постоянной комнаты запускай tui с --room; прежний режим tui без комнаты сохраняет поведение базового runtime.

## Локальный запуск базы

Для воспроизведения используй Node.js 24 или 26 и pnpm 12.16.1.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm ocean demo --json
pnpm ocean tui
```

`demo` выполняет сценарий без ключа модели. `ocean` — локальный скрипт запуска исходного CLI. Его help, внутренние имена пакетов `@runnets/*` и переменные `RUNNE_*` пока сохраняют имена базовой версии. Для реальных модельных запросов используется `DEEPSEEK_API_KEY` в окружении процесса. Постоянный файл `RUNNE_DB` хранит события выполнения задач. Для экспериментов с Ocean выбери отдельный файл в существующем каталоге.

```sh
pnpm check
pnpm format:check
```
