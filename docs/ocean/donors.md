# Из чего собираем Ocean

**Кодовая основа — RunneTS.** Ocean владеет профилями, комнатами, историей сообщений и решениями о запуске. Все новые компоненты v1 пишем на TypeScript. При первом импорте перенесены исходники, тесты, конфигурация workspace и техническая документация RunneTS. Другие проекты используются как источники конкретных решений.

## Происхождение базы

Исходный снимок взят 2 ноября 2026 года из рабочего дерева RunneTS поверх HEAD `410c53217dbb20b7d8e267a6b61368dba3c9a645`. Он включает локальные правки и новые исходники. Один checkout этого коммита не воспроизводит снимок. Контрольный SHA-256 для импортированных файлов в `apps/` и `packages/` — `796c19a3aafbca192681c49280787afa85f3ba755d1bd97c78883092defef6b5`. Для каждого пути по порядку сортировки Path в Python в хеш входят UTF-8 относительный путь, NUL и бинарный SHA-256 содержимого. Корневое имя пакета Ocean и скрипт запуска заданы в [package.json](../../package.json).

Вместе с кодом сохранены лицензия MIT, уведомления об авторстве и описание архитектуры базы. Git-история и конфигурация удалённого CI принадлежат исходному проекту. Импорты в исходниках используют прежние имена пакетов, что позволяет проверить перенос без одновременного изменения контрактов.

## Что переиспользуем

| Источник         | Что берём                                                                                                                                                 | Где и когда применяется                                                                                                                                                        |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| RunneTS          | Домен TaskRun, команды с идентификатором, атомарная запись событий и квитанций, SQLite, журнал действий инструментов, цикл модели, DeepSeek, CLI/TUI, ACP | Исполнение каждого адресованного боту хода. Новые сущности общения добавляем рядом с TaskRun. Существующие клиенты ACP сохраняют свой контракт.                                |
| OpenMausBot      | Каркас общения — постоянная личность бота, прямой диалог, состав группы, упоминание и выбор следующего участника                                          | Собственная реализация в домене Ocean. Сначала прямой чат, затем тот же механизм в комнате с несколькими ботами. Desktop, оболочка и сервер MausBot для этого не требуются.    |
| DeepSeek Harness | Восстановление контекста из журнала сессии, разделение временных фрагментов потока и зафиксированного ответа                                              | История личного чата и контекст участника группы. Используем существующий цикл модели в RunneTS, единственный владелец истории — Ocean.                                        |
| DSH Superagent   | Отделение поручения от попытки исполнения и входящего сообщения от полномочий                                                                             | Источник запроса, связь сообщения с TaskRun и явное разрешение на действие. Наблюдение за GitHub, автономный приём поручений и исходящие интеграции оставляем за пределами v1. |
| Runne (Rust)     | Проверки восстановления и отмены, включая завершение родителя при ещё работающем потомке                                                                  | Приёмка выполнения задач. Сохраняем неопределённый исход, если остановку подтвердить нельзя. Переноса Rust runtime в v1 нет.                                                   |

При точечном заимствовании кода фиксируем файл, исходную ревизию, лицензию и авторство до включения. Для первого этапа за пределами RunneTS взяты только проектные идеи.

Источники решений — [группы OpenMausBot](https://docs.openmausbot.com/docs/features/chat-and-teams), [сессии Harness](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md), [полномочия Superagent](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/main/docs/002-authorization.md), [Runne](https://github.com/ryltsevmikhail/Runne).
