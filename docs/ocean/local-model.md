# Local model adapter

## Implemented source contract

Ocean registers provider `ollama` for exact `qwen3:1.7b`, using a canonical HTTP or HTTPS loopback origin (127/8 or IPv6 ::1), with explicit `none` or `api_key` authentication. There is no environment lookup, implicit cloud fallback, model download, create/pull request, process launch or backend startup. This is an initial text/tool profile; images and nonempty reasoning refuse before traffic.

The application connection service can save desired active settings without an executable model or placeholder catalog entry. Its optional typed `factory.localBootstrap` capability prepares metadata checks without constructing a provider. An unqualified row has `localQualification: null`, `unverified` status and an empty catalog. Set receipts remain frozen snapshots; qualification never rewrites them.

Only an explicit successful owner `check` can publish qualification in the existing connection row. Evidence includes exact full lowercase 64-hex manifest digest, backend version, capabilities and requested context. Changed evidence atomically increments revision; identical evidence keeps it. `check.revision` and `lastCheck.revision` identify the inspected configuration R; returned status may identify R+1 or another winning owner operation. Failed rechecks retain previous evidence/revision and record failure, so a connected cached status can coexist with a failed last check. Stale results report `persisted: false` and never rebase. Fresh sets/reconnects and key removal invalidate evidence; disconnect retains it while refusing checks/use. Earlier records decode missing qualification as null; schema 21 materializes null without altering frozen receipt bytes.

Established auth-none set/status/check/admission reads no secrets and performs no external credential lookup. An explicit transition from API key to none still completes recoverable deletion and verification of the previous credential. Auth-none records with a secret reference refuse before credential reads. API-key checks use only the saved reference.

Admission synchronously captures persisted evidence and capabilities. After the runtime has durably started each model request, the provider performs metadata preflight before `/api/chat`, comparing against that frozen evidence. Failure or drift means inference `not_sent`, with no tools. It never updates qualification from a stream or silently adopts changed tags. Previously admitted turns retain their earlier provider and identity after an owner check publishes a new revision.

The metadata profile uses only GET `/api/version`, GET `/api/tags`, and POST `/api/show` with `{model:"qwen3:1.7b",verbose:true}`. All share a maximum 10-second budget; preflight additionally shares the inference deadline. Byte caps are 64 KiB/version, 1 MiB/tags and 16 MiB/show. Tags have at most 4096 entries; verbose tensors 1..16384, names at most 512 characters, types 64, shapes 1..8 positive safe dimensions. Capabilities have at most 32 bounded entries; backend version is nonempty and at most 128 characters. Oversize or unsupported evidence refuses without weaker fallback.

Qualification requires matching GGUF/qwen3/2.0B/Q4_K_M details, an unambiguous exact tag/model with full manifest digest, explicit completion/tools, architecture capacity at least 4096, positive validated tensors and no remote declaration. The marketing tag remains `qwen3:1.7b`; the pinned native artifact reports `parameter_size:2.0B` (2,031,739,904 parameters from its 311 tensor shapes), rather than the provisional 1.7B expectation. Other parameter-size values refuse. Unknown origin refuses. Configured context 4096 records Ocean's explicit request, not an observed backend allocation/default; effective catalog context is 4096. Maximum output architecture metadata remains null. Requests always set `think:false`, `stream:true`, `num_ctx:4096` and `num_predict:512` by default; explicit positive safe `maxTokens` up to 512 is sent exactly, larger/invalid bounds refuse without clamping.

Native chat uses strict LF-delimited JSON (CRLF accepted), fatal UTF-8, 256 KiB per record and 8 MiB total. Unterminated EOF refuses. Only `done:true` with known stop/length and fully validated framing completes; length cannot authorize tools. Tools are buffered until completion; repeated same-name calls in one assistant round refuse because this profile correlates native results by `tool_name`. Ocean IDs remain distinct across continuation rounds. Missing terminal token counts stay unavailable, never inferred as zero. Valid actual terminal usage survives a later framing failure, with unknown completion and no tools.

Local metadata/inference and DeepSeek metadata/inference explicitly disable redirects at the fetch seam, matching OpenAI/Anthropic. No redirected transcript or credential is resent. Redirected inference remains unknown once dispatched. There is no inference retry; probe traffic is metadata, not an inference attempt. Public provider deadlines accept 0..2147483647 milliseconds, where zero disables only the inference timer. Higher values overflow Node timers or throw and refuse before provider construction.

## Trust and remaining qualification

The parser evidence is pinned to official Ollama source revision [`2e7b870fbcec32da4b8864a1f715d7809c801490`](https://github.com/ollama/ollama/tree/2e7b870fbcec32da4b8864a1f715d7809c801490): [API types](https://github.com/ollama/ollama/blob/2e7b870fbcec32da4b8864a1f715d7809c801490/api/types.go) and [local tensor loading](https://github.com/ollama/ollama/blob/2e7b870fbcec32da4b8864a1f715d7809c801490/server/routes.go). That pin is supporting source evidence, not an installed backend version. Fixtures use synthetic versions and digests.

Metadata trusts the genuine owner-configured backend. It does not attest every weight byte or a malicious proxy. A tag can change after preflight and before inference; returned model names are checked where supplied, but digest selection is not atomic. Metadata cannot prove offline execution, cloud disablement, runner allocation, external cancellation or cleanup.

The candidate remains unqualified for release until a separate native gate records actual backend version, full installed artifact digest/presence/integrity, actual context allocation, cloud-disabled backend, isolated networking, offline text/tool fidelity, resource measurements and cold/warm latency. The library's short digest and advertised 1.4 GB size are not qualification. No backend, weights, credentials or real inference were used for source fixture verification. Owner CLI/TUI forms and richer qualification presentation remain separate exposure work; the lifecycle described here is the application service contract.
