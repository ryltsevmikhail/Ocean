# Ocean Desktop

Импортирован полный Desktop из коммита `1c8d8c3` (2026-11-02). Это текущий
Electron/Vue клиент внутри Ocean; установленное приложение отдельно. Общий
долгоживущий runtime пока только запланирован: этот host не использует ACP или
локальный socket и не обеспечивает detach/reconnect активного хода. См.
[границу интеграции](../../docs/integration/desktop-client.md) и
[план shared runtime](../../docs/ocean/shared-runtime.md).

Локальный текстовый клиент для Linux. Из корня checkout с Node 26 и pnpm 12.16.1:

```sh
pnpm install --frozen-lockfile
pnpm --filter @ocean/desktop start
```

«Создать Ocean Team» добавляет отсутствующие профили dev и review и создаёт общую комнату. В поле «Кому» выберите dev, отправьте задачу, затем выберите review и задайте вопрос о результате. Отправка всем сохраняет заметку. Для личного диалога нажмите «＋», выберите тип комнаты и одного участника.

Main запускает отдельный Node 26 с CLI этого checkout. Профиль находится в каталоге Electron userData, в `conversation/profile`. При запуске клиент перечитывает историю и состояния ходов через CLI. Ключ для живых ответов задаётся в локальном окружении CLI через `DEEPSEEK_API_KEY`. Кнопка отмены посылает SIGINT процессу активной отправки. Статус `uncertain` требует разбора хода в Ocean CLI.

## Вложения

Кнопка со скрепкой, перетаскивание и вставка из буфера принимают до четырёх файлов по 10 МБ. PNG, JPEG, GIF и WebP показываются перед отправкой и в истории. Текстовые файлы имеют предпросмотр содержимого, другие форматы — карточку с размером и типом. Оригинал сохраняется через системный диалог.

Файлы лежат в приватном каталоге Electron userData, в `conversation/attachments`. Main проверяет комнату, размер, SHA-256 и принадлежность идентификатора. До обращения к CLI сохраняются исходные байты и квитанция запроса. История runtime содержит версионированные ссылки. Вложение в Desktop связано с комнатой и конкретным пользовательским сообщением. При переносе профиля требуется сохранить весь каталог `conversation`, включая вложения. Команда CLI backup сохраняет базу отдельно.

В текущем текстовом подключении DeepSeek получает ограниченные выдержки текстовых файлов и описание остальных вложений. Распознавание картинок, PDF и архивов потребует отдельного API мультимодального провайдера. Для общего runtime предлагается контракт загрузки immutable blob, привязки id/sha256 к сообщению и выдачи данных только в контексте комнаты. Это отдельный шаг согласования с владельцем runtime.

## Проверка окна на Wayland

```sh
pnpm build
pnpm --filter @ocean/desktop bundle
node apps/desktop/qa/smoke.mjs
```

Проверка открывает Electron с временным приватным профилем. Первый запуск проверяет ошибку CLI без ключа. Последующие запуски подменяют HTTP-ответ провайдера в отдельном тестовом процессе Node. Комнаты, история, построение контекста и обработка отмены проходят через обычный CLI и SQLite.

## Следующие контракты

Для coding review нужен API задач с идентификатором комнаты, неизменяемым changeset и его хешем, результатами разрешённых тестов, подтверждением конкретной операции и вердиктом по этому хешу. До согласования с владельцем runtime Desktop поддерживает текстовый разбор результата в комнате. macOS Apple Silicon и упаковка приложения требуют отдельного прогона.
